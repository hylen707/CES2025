# Reading room

The review has two routes. Begin with the [commercial thesis](01-commercial-thesis.md) to inspect buyer tasks, category boundaries and value capture. Begin with [engineering evidence](03-engineering-evidence.md) to follow assumptions, designs, protocols and implementation failures.

Use the [analyst desk](02-analyst-desk.md), [paper atlas](04-paper-atlas.md) and [deployment record](05-deployment-record.md) as source cards, rather than treating the number of references as proof of a conclusion. The [synthesis](06-synthesis-and-agenda.md) identifies what could change each assessment.

Canonical records are [sources.json](sources.json), [forecasts.json](forecasts.json) and [theses.json](theses.json). Generated companions are [forecast arithmetic](market-checks.json), [forecast CSV](forecasts.csv), [coverage summary](summary.json) and [BibTeX](references.bib).

The [method](METHOD.md) explains selection and access limitations. [Format references](FORMAT.md) describe the publication-catalog and paper-linked experiment patterns. The earlier [evidence workbench](../research/README.md) retains the source audit and bounded technology decisions.
