# A publication-led sector review

The CES review uses a reading-room structure: a commercial argument, an engineering interpretation, annotated source catalogs, deployment context and a falsifiable research agenda. Source cards sit behind the narrative rather than leading the root overview with a repeated metrics grid.

The format draws on these inspectable patterns:

**[trailofbits/publications](https://github.com/trailofbits/publications/blob/cb3b192dc060b93221f0edb45c77d44422bbc0f2/README.md#L59-L62).** Publication catalog organized by document type, venue and year.

**[mupq/pqm4](https://github.com/mupq/pqm4/blob/6ff2be970f6f4592b341d432042063ceacf424a2/README.md#L13-L25).** Paper-linked experiments with explicit platform and measurement scope.

The publication catalog informs separation by document type and venue. The paper-linked experiment documentation informs treatment of platform, measurement and reproducibility conditions. These are editorial and methodological adaptations. No upstream code, report PDFs, branding or assets are imported, and no endorsement is implied.

Exact commits and file identities are in [format-benchmarks.json](format-benchmarks.json). The earlier [method register](../research/BENCHMARKS.md) remains available for the supporting evidence workbench.
